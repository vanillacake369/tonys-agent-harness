Start the Korean technical blog workflow through the blog-writing skill.

Use skl-post-blog-ljh as the canonical workflow. The command is a public
facade; the skill owns phase questions, tone rules, heading hierarchy,
approval gates, and writing validation.

Follow these phases in order:

1. Confirm topic, audience, source material, personal-experience scope,
   coverage, depth, citations, and output path.
2. Propose the narrative question, section skeleton, and detailed TOC.
3. Confirm scope and estimate length and whether the post should be split.
4. Show one representative section slice before writing the full post.
5. Wait for explicit approval of the sample and format.
6. Confirm the final output path.
7. Write the approved post and run focused structure checks.

Do not write the final post before the sample approval and output-path
confirmation. Preserve existing user changes and do not expose private
company identifiers, credentials, secrets, internal URLs, or personal data.
