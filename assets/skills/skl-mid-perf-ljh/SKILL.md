# Mid-Performance Engineering Skill

- Establish a reproducible baseline before changing code.
- Identify a measured bottleneck and state a falsifiable hypothesis.
- Apply one scoped optimization at a time.
- Compare before/after latency, throughput, resource use, and correctness.
- Preserve rollback and regression evidence.

Performance changes remain implementation mutations and require the same
traceability, test, and approval gates as other code changes.
