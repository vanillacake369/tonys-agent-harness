# Pre-Research Engineering Skill

Use this capability when a request depends on repository context, technology
choice, provider compatibility, or project bootstrap.

- Map callers, dependencies, generated files, and implicit contracts first.
- Prefer local evidence and official documentation.
- Record source, fact, constraint, unknown, license, maintenance, and
  operational-cost information separately.
- Propose configuration or Skill changes as a diff; do not overwrite existing
  policy without approval.
- Remain read-only.
