# Post-Documentation Engineering Skill

- Link documentation to PRD IDs, ADRs, changed files, tests, and verification.
- Keep canonical policy in AGENTS.md and project specs in the configured spec root.
- Distinguish confirmed facts, assumptions, unresolved risks, and next actions.
- Do not duplicate or silently redefine source-of-truth contracts.
- Handoff artifacts must be reproducible by the next session.
