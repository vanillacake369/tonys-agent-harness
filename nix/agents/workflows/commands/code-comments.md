변경 코드에 의미 중심 주석을 추가하거나 낡은 주석을 정리한다.

# Task
$ARGUMENTS

# Rules
요청된 언어·톤·주석 형식을 먼저 확인하고 기존 프로젝트 스타일을 따른다. 코드가 무엇을 하는지 반복하지 말고 왜 그렇게 해야 하는지, 불변식·외부 제약·안전상 주의를 설명한다. 동작 변경과 무관한 대규모 주석 정리는 하지 않는다. 생성 코드·명백한 helper에는 주석을 강제하지 않는다.

# Output
Changed files, comment rationale, omitted comments with reasons, and focused verification.
