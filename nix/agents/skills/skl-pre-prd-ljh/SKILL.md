# Pre-PRD Engineering Skill

Use this capability before implementation when requirements, domain terms,
acceptance criteria, or component boundaries are incomplete.

- Inspect the repository before asking questions that local evidence can answer.
- Separate confirmed facts, assumptions, conflicts, and blocking questions.
- Produce Markdown PRD content under the project `docs/agent/prd/` SSoT.
- Include requirement IDs, non-functional requirements, dependencies, and
  acceptance criteria.
- Delegate test, code, and infrastructure design inputs without granting them
  implementation authority.

Absorbed VPP guidance: `clarify`, `grill-with-docs`, and `to-prd`.
