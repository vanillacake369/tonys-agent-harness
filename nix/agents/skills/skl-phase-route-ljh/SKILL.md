# Phase Routing Skill

Classify the request before selecting specialist capabilities.

- Use deterministic signals for risk and required approval.
- Use repository research for answerable uncertainty.
- Ask a spec question only when the answer changes design or acceptance.
- Select the minimum lifecycle skills needed for the route.
- Keep Judge output advisory and preserve fail-closed policy results.
